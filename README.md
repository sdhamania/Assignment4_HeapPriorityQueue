# Assignment 4 — Heap Sort, Priority Queue, and Scheduler Simulation

Algorithms and data structures assignment implementing heap sort, a binary-heap priority queue, and a priority-based scheduler simulation.

## Requirements

- Python 3.9+
- Dependencies in [`requirements.txt`](requirements.txt)

## Setup

```powershell
cd "Assignment4_HeapPriorityQueue"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Or run without activating the venv:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Run

Self-test heap sort:

```powershell
python heap_sort.py
```

Self-test priority queue:

```powershell
python priority_queue.py
```
